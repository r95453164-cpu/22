# 22 · 11 · 22:22

Маленький сайт для красивой девочки и красивой даты.
Чистые HTML + CSS + JS, без сборки и зависимостей: открывается двойным кликом по `index.html`.

## Что внутри

```
index.html    — разметка
css/style.css — стили, шрифты, адаптив
js/app.js     — лепестки, часы, сердечки, «перем-перем»
assets/       — фотографии и шрифты (локальные, ничего не грузится извне)
```

## Секции

- **Обложка** — «22:22», живые лепестки на canvas. Если нажать на время — маленький секрет.
- **Пять причин** — почему она красивая (пункт 5 — самый честный).
- **Галерея** — розы, закатное небо и поле роз в виде полароидов.
- **Цитата** — единственная пафосная строчка, но она заслужила.
- **Часы** — текущее время и обратный отсчёт до следующего 22:22 (в саму минуту 22:22 блок светится).
- **Письмо** — то, что обычно не говорят вслух.
- **Сердечко** — счётчик с сохранением в localStorage.

Кнопка «перем-перем» включает очень тихую музыкальную шкатулку (Web Audio, синтез на ходу — никаких mp3), плюс есть колокольчик на каждое сердечко.

## Как открыть

Локально: открыть `index.html` в браузере.

Онлайн: GitHub Pages → Settings → Pages → Source: `main` / root.
Сайт будет доступен по адресу `https://r95453164-cpu.github.io/22/`.

## Мелочи

- Шрифты (Cormorant Garamond и Jost, кириллица + латиница) лежат прямо в репозитории — сайт не зависит от Google Fonts.
- Уважает `prefers-reduced-motion`: анимации и лепестки отключаются.
- Картинки: сгенерированные и подобранные вручную, лежат в `assets/`.
